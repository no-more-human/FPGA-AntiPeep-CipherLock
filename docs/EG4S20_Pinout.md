## 📌 一、核心板资源与接口总览

**DMZ-EG4S20（大拇指系列）** 是一款基于国产安路科技（Anlogic）**EG4S20BG256** 主控的高集成度 FPGA 开发板，外设丰富且扩展性极强：

* **主控芯片**：Anlogic EG4S20BG256（256球 BGA 封装，20K LE，1Mbits BRAM，12位内部多通道 ADC，合封 2M×32bit SDRAM）。
* **板载时钟与复位**：50MHz 有源晶振（`R7`）、独立微动复位按键 KEY1 / RSTn（`E3`，低电平有效）。
* **板载显示与声光**：4 位共阴极数码管、8 路高电平驱动 LED、1 路无源电磁蜂鸣器（`H11`）。
* **板载人机输入**：4×4 白色微动轻触按键矩阵、8 位拨码开关（SW0~SW7）。
* **调试与通信双接口**：
  * **右上角 JTAG 接口**：一根 USB 线即可完成供电、FPGA 比特流下载与在线逻辑分析调试。
  * **右下角 UART2USB 接口**：**开发板自带独立 CH340 USB 转串口芯片**，直连 FPGA 的 `D12 (TX)` 和 `F12 (RX)` 管脚。**上位机通信仅需插上这根 USB 线，彻底免去外接 USB-TTL 串口小板！**

## 🔌 二、纯板载原生外设架构（零杜邦线、零外设损坏风险）

为彻底杜绝杜邦线虚接、供电不稳及外接硬件接触不良隐患，本项目**彻底拔除全部外接扩展模块，100% 依托 DMZ-EG4S20 开发板板载原生外设 + PC 上位机数字孪生协同工作**：

1. **极简硬件拓扑（全机仅需 2 根 USB 线）**：
   - **右上角 `USB JTAG`**：负责开发板供电与 FPGA 比特流烧录；
   - **右下角 `UART2USB`**：直连板载 CH340 芯片，以 115200bps 与 PC 双向通信。
2. **输入收敛至板载 4×4 白色轻触微动开关矩阵**：
   - 彻底废弃外接薄膜键盘，使用板载 16 颗白色微动按键作为唯一主键盘；
   - 行管脚：`E10, C10, F9, D9`（配置内部上拉 `PULLUP`）；
   - 列管脚：`E11, D11, C11, F10`（轮流拉低扫描）；
   - 走线补偿：`rtl/keypad_scan.v` 内部译码器已适配 180° 旋转补偿，正面操作视角与丝印完全一致。
3. **显示与声光全部由板载组件承载**：
   - **开锁指示**：`LED2 (B16)` 代替原外接舵机，开锁成功高电平点亮 3 秒；
   - **音效提示**：板载无源蜂鸣器（`H11`）输出按键音、错误警告、锁定警报、成功和弦与持续防撬急促警报；
   - **OLED 屏幕迁移**：原 0.96 寸物理 OLED 升级为 PC 端 **数字孪生 OLED HUD**，通过串口快照 `@O<6位Hex>\n` 毫秒级自同步。

## ⚡ 三、串口通信说明：全面依托板载 CH340 芯片

硬木课堂 DMZ-EG4S20 核心板**已在硬件电路上集成了 CH340 虚拟串口芯片**，并引出至板载右下角的 **`UART2USB` 接口**：

```
                    【串口交互拓扑架构】
┌─────────────────────┐      标准 USB 线 (Type-C)     ┌────────────────────────────────────┐
│      PC 上位机      │ ◄───────────────────────────► │       DMZ-EG4S20 开发板            │
│  (Python AI 监控中枢)│                                │ • 右下角 UART2USB 口 (CH340)       │
│  COM口 @ 115200bps   │                                │ • FPGA 管脚直连:                   │
└─────────────────────┘                                │   - 发送 uart_tx : D12             │
                                                       │   - 接收 uart_rx : F12             │
                                                       └────────────────────────────────────┘
```

1. **彻底免去外部 USB-TTL 串口小板**；
2. **极简即插即用**：用 Type-C 数据线插入右下角 `UART2USB` 口，电脑设备管理器自动识别为 `USB-SERIAL CH340 (COMx)`，启动 `pc/main.py` 即可通信。

## 🎯 五、连线自检清单与快速验证 (零飞线)

1. **第一步：物理接线**：
   - 彻底拔掉四周排母上的全部外接杜邦线与模块；
   - 仅用 2 根 USB 线分别接入右上角 `USB JTAG` 与右下角 `UART2USB`。
2. **第二步：下载比特流**：
   - 使用安路 TD 工具将生成的 `lock.bit` 下载至 FPGA；
3. **第三步：板载功能验证**：
   - `LED0` 呈 **1Hz** 平稳心跳闪烁；
   - 4 位数码管显示 `IdLE`；
   - 敲击板载左上角第 1 颗按键，`LED1` 瞬亮，蜂鸣器短鸣，数码管显示 `P- 1`；
   - 输入默认出厂密码 `123456#`，蜂鸣器奏响和弦，`LED2` 点亮 3 秒开锁，数码管显示 `OPEn`；
   - 在闭锁待机状态下，将板载 `SW1` 向上拨动模拟非法撬门，蜂鸣器立即进入急促高频报警，`LED7` 报警常亮，串口向 PC 上报 `'X'` 撬门事件！
   - 运行上位机程序 `python pc/main.py`，PC 界面实时显示数字孪生 OLED 与安全监控状态！
