## 📖 项目概述 (Project Overview)

传统的电子密码保险箱面临两大严峻安全威胁：**背后偷窥/旁路拍摄** 与 **受胁迫状态下的强制开门**。

本项目设计了一种基于**国产安路 EG4S20 FPGA 硬件安全内核**与 **PC 端轻量化 Edge AI 视觉模型**的软硬异构智能保险箱系统：
- **硬核底座（FPGA 下位机）**：脱离 PC 可作为独立的全功能高可靠物理密码箱运行。硬件全流水线驱动开发板板载原生外设，实现板载 4×4 矩阵微动按键输入、板载 4 位数码管/8 路 LED/无源蜂鸣器多模式声光指示与报警、LED2 开锁状态指示与板载 SW1 门磁防开锁超时检测。
- **智能升维（PC 上位机 Edge AI）**：利用 USB 广角摄像头捕捉现场操作环境，运行轻量化 YOLOv8 视觉防窥引擎。一旦检测到侧后方有人探头、聚集偷窥，毫秒级通过工业级串口注入防御指令，触发 FPGA 瞬间熄屏阻断并留存抓拍证据。

## 📡 串口通信协议标准 (UART Protocol)

- **波特率**：`115200 bps`（降级备选 `9600 bps`）
- **数据帧格式**：`8 数据位, 无校验位 (None), 1 停止位 (8-N-1)`
- **双向单字节指令集规范**：

| 发送方 | 接收方 | 指令字符 | 协议语义 | 触发条件与动作响应 |
| :---: | :---: | :---: | :--- | :--- |
| **PC 上位机** | FPGA | `'S'` | **Safe (环境安全)** | 视野内恢复为单人正常操作；FPGA 恢复终端显示正常交互、解挂键盘并清除反挟持状态 |
| **PC 上位机** | FPGA | `'P'` | **Peep (窥视挂起)** | 检出背后聚集或侧后探头偷窥；FPGA 瞬间熄屏（仅显中间横杠）、挂起常规输入并蜂鸣告警（仍保留反挟持求救） |
| **PC 上位机** | FPGA | `'R'` | **Remote Unlock (远程开锁)** | PC 人脸核验通过或管理员远程授权开锁；FPGA 直接开锁 3 秒（LED2 高亮保持，锁定态下硬件拒绝响应） |
| **FPGA 下位机** | PC | `'U'` | **Unlocked (开锁成功)** | 密码正确或虚位密码提取合法；PC 上位机记录日志并抓拍开门者留存 |
| **FPGA 下位机** | PC | `'K'` | **Relocked (重新闭锁)** | 3 秒开锁倒计时结束或按 `C` 键手动提前闭锁；PC 数字孪生仪表盘同步恢复闭锁状态 |
| **FPGA 下位机** | PC | `'E'` | **Password Error (单次输错)** | 单次密码校验不通过；PC 上位机记录错误告警日志 |
| **FPGA 下位机** | PC | `'L'` | **Locked (暴力破解锁定)** | 连续输错 3 次锁定系统 60 秒；PC 触发声光报警并启动连拍取证 |
| **FPGA 下位机** | PC | `'T'` | **Lock Timeout End (锁定结束)** | 60 秒硬件锁定倒计时归零自动解封；PC 同步解除锁定告警状态 |
| **FPGA 下位机** | PC | `'D'` | **Duress (反挟持静默报警)** | 用户输入胁迫密码 `654321`，表面正常开锁麻痹歹徒，底层静默发 `'D'` 通知上位机后台连拍取证（已过滤 `'U'` 防止混发） |
| **FPGA 下位机** | PC | `'A'` | **Door Alert (门未关好警报)** | 开锁后门磁处于打开状态超过 15 秒未关门；上位机记录超时告警并抓拍 |

## ⌨️ 4×4 矩阵键盘按键映射与交互定义

开发板板载 4×4 白色微动轻触按键共 16 个物理按键，系统为每个按键赋予了明确的安防与业务功能定义（RTL 内部已适配 180° 旋转补偿，正面视角与丝印完全一致）：

| 键位 | 编码 (Hex) | 键面字符 | 按键类型 | 核心功能与交互行为说明 |
| :---: | :---: | :---: | :---: | :--- |
| **0 ~ 9** | `0x0` ~ `0x9` | `0` ~ `9` | **数字输入** | 密码输入与新密码设置录入。按下一键蜂鸣器发 1kHz 提示音，终端显示动态更新掩码 `*`，数码管显示当前位数。 |
| **\*** | `0xE` | `*` | **退格 / 取消** | **双重容错逻辑**：<br>1. 正在输入字符（`len > 0`）：单步回退删除最后 1 位；<br>2. 缓冲区为空（`len == 0`）：直接**取消当前模式**（取消改密/取消录入/取消应急重置），安全平稳退回待机主界面。 |
| **#** | `0xF` | `#` | **确认 / 提交** | **多模式确认键**：<br>1. **开锁核验**：提交 6~16 位输入进行滑动窗口模式匹配判决（未满 6 位按 `#` 仅发提示音，不扣罚错误次数）；<br>2. **改密/录入/恢复**：提交当前 6 位密码，推进入下一步确认或写入。 |
| **A** | `0xA` | `A` | **新用户设置密码** | **首次录入通道**（仅在默认密码 `123456` 尚未修改时可用；改密后按 `A` 拒绝进入并提示音，防旁人直接篡改）：<br>`按 A` $\to$ 终端显示提示 `输入新密码` $\to$ 输 6 位新密码按 `#` $\to$ 提示 `重复新密码` $\to$ 再次输入按 `#` $\to$ 写入密码寄存器生效。 |
| **B** | `0xB` | `B` | **修改密码 (改密)** | **老用户改密通道**（强权限闭环，验旧改新）：<br>`按 B` $\to$ 终端显示提示 `输入旧密码` $\to$ 按 `#` 校验（输错扣罚并报警退回）$\to$ 验密通过后 `输入新密码` $\to$ 按 `#` $\to$ `重复新密码` $\to$ 按 `#` $\to$ 写入生效。 |
| **C** | `0xC` | `C` | **手动提前闭锁** | 开锁成功后若无需等待 3 秒自动闭锁，按 `C` 可立即提前闭锁（熄灭 LED2 开锁指示灯）并向 PC 上报 `'K'`。 |
| **D** | `0xD` | `D` | **硬件应急恢复** | **忘记密码硬件重置通道**（需先将开发板拨码开关 `SW7 (A14)` 拨上开启硬授权）：<br>待机态 `按 D` $\to$ 终端显示 `应急重置 / 请输入密码` $\to$ 输入 6 位硬件恢复码 `937158` 按 `#` $\to$ 密码强制恢复为初始值 `123456`（连续输错 3 次同样触发 60 秒锁定）。 |

> **防呆保护机制**：处于 `A`（录入）或 `B`（改密）模式时超过 **15 秒**无操作，或处于 `D`（应急重置）模式超过 **30 秒**无操作，硬件看门狗定时器自动超时放弃，安全退回待机，防止状态机被占死。

## 💻 PC 上位机安防控制中枢与三层自适应防窥模型

PC 端基于 Python (Tkinter + YOLOv8 + PySerial + OpenCV) 构建，定位为**“环境防窥天眼、设备状态监控与取证黑匣子”**：

### 1. 监控面板大屏功能区布局
* **左半区：实时视觉画面与 AI 目标标注**
  * 直接调用本地/USB 摄像头（`cv2.VideoCapture(0)`），以低延迟帧率呈现。
  * **目标标注框**：
    * **绿色框**：标注正前方的操作者本人（标记 `User: Active`）。
    * **红色告警框**：标注侧身探头、背后聚集逼近的偷窥者（标记 `Peeping Alert!`）。
  * **人脸识别状态指示**：白名单核验状态、单人稳定 2 秒核验开锁按钮引导。
* **右半区：终端显示与锁体环境控制**
  * **终端显示组件**：1:1 动态仿真呈现四行交互菜单、密码掩码与防窥横杠（`----------------`）。
  * **锁体与环境状态**：实时映射底层开锁、闭锁、60s 试错锁定倒计时与门未关严状态。
  * **交互与测试控制按钮**：`[测试 P · 防窥]`、`[测试 S · 解挂]`、`[测试 R · 开锁]`，支持无需摄像头一键模拟联调。
  * **取证存储状态**：一键打开本地数据存储目录。
* **底部区：多标签页管理中枢**
  * **运行日志**：带毫秒级时间戳的事件滚动审计列表，支持一键导出 CSV 报告。
  * **密码管理**：支持在线校验旧常规密码并提交修改新常规密码/胁迫密码。
  * **模拟验收**（`--demo` 模式）：内置全真软件模拟器，支持免硬件全流程演练。

### 2. 自适应防窥与取证判决模型
为了避免背景走动路人频繁误触，PC 端采用空间与时间融合判决模型：
1. **第一层：空间几何 ROI 与身高比例过滤**：设置 `min_person_height_ratio=0.25`，自动剔除背景远处走过的路人。
2. **第二层：双向时间滞后防抖滤波（Temporal Hysteresis）**：多人目标必须持续停留达到 `peep_enter_seconds`（默认 0.8 秒）才触发防窥熄屏 `'P'`；恢复单人/无人且持续达到 `peep_exit_seconds`（默认 1.2 秒）才下发 `'S'` 恢复，彻底杜绝状态频繁抖动。
3. **第三层：人脸核验与事件级自动取证**：单人白名单稳定识别 2.0 秒方可获得核验开锁资格；收到 `'U'`/`'D'`/`'L'`/`'A'`/`'P'` 等事件自动触发快照抓拍（归档至 `data/live/evidence/`）与 15 秒滚动录像（归档至 `data/live/recordings/`）。

## 🔐 密码认证规范与虚位密码机制

1. **日常开锁免录人脸**：
   * 人来到保险箱前，直接敲键盘输入密码即可开锁，无需预先录入人脸库。
   * PC 摄像头仅负责环境防窥与开门自动抓拍留底，不卡控开门权限，保障断网脱机时 100% 独立可用。
2. **6 ~ 16 位自适应虚位密码**：
   * 敲击长度在 **6 至 16 位** 任意浮动（例：`乱码 + 6位真密码 + 乱码 + #`），绝不强制凑满 16 位。
   * FPGA 内部移位 FIFO 永远保存最近 16 位输入，在按 `#` 的瞬间，通过内部 **11 组硬件并行比对器在 20 纳秒（单时钟周期）内全并行完成模式匹配**，纳秒级提取真密码，兼具防旁路推演与超高硬件实时性。

## 🚀 快速上手指南 (Quick Start)

### 1. 硬件端：安路 TD 工程构建与烧录

1. 启动 **Anlogic Tang Dynasty (TD)** 软件（推荐版本 TD 5.6+）。
2. 在主菜单点击 `Project` $\to$ `Open Project...`，选择本项目根目录下的 [`lock.al`](./lock.al)。
3. 在左侧 Project View 确认工程文件关联无误：
   - Design Files: `rtl/clk_tick.v`, `rtl/top.v`
   - Constraints: `lock.adc`
4. 双击运行 **Generate Bitstream** 生成比特流固件。
5. 使用 USB 下载线连接开发板 JTAG 接口，通过 **Download** 工具烧录至 FPGA。
6. **验证现象**：板载 `LED0` 以精确的 **1Hz**（0.5s 亮、0.5s 灭）平稳闪烁，说明硬件底座、基准时钟与引脚约束完全正常。

---

### 2. 软件端：上位机启动与联调

上位机支持物理串口连接与脱机模拟运行两种模式：

#### 安装运行环境依赖

```bash
# 建议在 Python 3.9+ 虚拟环境中执行
pip install -r requirements.txt
```

#### 启动 PC 上位机监控主控台
```bash
# 启动可视化安防主控台 (支持自动扫描物理 COM 口与一键联调)
```
