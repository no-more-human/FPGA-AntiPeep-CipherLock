## 📖 项目概述 (Project Overview)

传统的电子密码保险箱面临三大严峻安全威胁：**背后偷窥/旁路拍摄**、**受胁迫状态下的强制开门** 以及 **外部指令重放与硬件逆向明文窃取**。

本项目设计了一种基于**国产安路 EG4S20 FPGA 硬件安全内核**与 **PC 端轻量化 Edge AI 视觉模型**的软硬异构智能保险箱系统：
- **硬核底座（FPGA 下位机）**：脱离 PC 可作为独立的全功能高可靠物理密码箱运行。片上内置 **RO-TRNG 环形振荡器物理真随机数发生器**、**全芯片 PRESENT 硬件密文哈希（主密码与恢复码零明文驻留）**、**11 组单周期全并行虚位滑窗比对核**，采用**纯板载原生外设架构**（板载原生 LED2 高可靠开锁驱动指示 + 4 位共阴数码管 + 无源蜂鸣器立体反馈，具备高稳定与强抗干扰特性）。
- **智能升维（PC 上位机 Edge AI）**：利用 USB 广角摄像头捕捉现场操作环境，运行轻量化 YOLOv8 视觉防窥引擎。一旦检测到侧后方有人探头、聚集偷窥，毫秒级通过工业级串口注入防御指令，触发 FPGA 瞬间熄屏阻断并留存抓拍证据。

| **LED5** | **E13** | `door_open` | 随门磁变化 | 门磁开闭实时指示（门开点亮，门闭熄灭） |
| **LED6** | **E16** | `err_count >= 1` | 灭 | 错误历史指示 1（累计输错 $\ge 1$ 次常亮） |
| **LED7** | **F16** | `(err_count >= 2) \| door_alert` | 灭 | 错误历史指示 2 或门超时未关报警（报警时常亮） |

## 📡 串口通信协议标准 (UART Protocol)

- **波特率**：`115200 bps`（降级备选 `9600 bps`）
- **数据帧格式**：`8 数据位, 无校验位 (None), 1 停止位 (8-N-1)`
- **双向单字节指令集规范**：

| 发送方 | 接收方 | 指令 / 帧格式 | 协议语义 | 触发条件与动作响应 |
| :---: | :---: | :---: | :--- | :--- |
| **PC 上位机** | FPGA | `'S'` | **Safe (环境安全)** | 视野内恢复为单人正常操作；FPGA 恢复终端显示正常交互、解挂键盘并清除反挟持状态 |
| **PC 上位机** | FPGA | `'P'` | **Peep (窥视挂起)** | 检出背后聚集或侧后探头偷窥；FPGA 瞬间熄屏（仅显中间横杠）、挂起常规输入并蜂鸣告警（仍保留反挟持求救） |
| **PC 上位机** | FPGA | `'R'` | **Remote Unlock Request (请求挑战)** | PC 人脸核验通过请求远程开锁；FPGA 不直接开锁，而是生成 8-bit 物理熵混合挑战随机数并通过 `'?' + <Nonce>` 下发 |
| **FPGA 下位机** | PC | `'?' + <Nonce>` | **Auth Challenge (挑战随机数)** | 2 字节二进制帧（`0x3F` + 1 字节 Nonce），由片上 3 组素数自激 Ring Oscillator (RO-TRNG) 物理微热抖动差分去偏熵注入 LFSR 动态生成，每次请求物理绝对唯一 |
| **PC 上位机** | FPGA | `'!' + <MAC>` | **Auth Response (PRESENT-MAC 应答)** | 2 字节二进制帧（`0x21` + 1 字节 MAC），经 2 轮 PRESENT S-Box + ARX 验算；核验通过开锁 3 秒，核验失败计入 `remote_auth_err` 触发阶梯死锁 |
| **PC 上位机** | FPGA | `'H'` | **Hardware Audit Query (黑匣子回读)** | 请求回读 FPGA 片上 ERAM9K 环形安全黑匣子中最新一条硬件审计记录 |
| **FPGA 下位机** | PC | `@H<8-Hex>\n` | **BRAM Blackbox Frame (硬件审计帧)** | 11 字节帧，承载 32-bit 硬件黑匣子记录：`{12-bit 硬件秒时标, 8-bit 链式PRESENT-MAC, 4-bit 状态码, 8-bit 事件码}` |
| **FPGA 下位机** | PC | `@O<6-Hex>\n` | **Virtual OLED Snapshot (状态快照帧)** | 9 字节帧，毫秒级同步底层状态码、掩码长度、错误次数及 9-bit 阶梯锁定倒计时（支持 `60s -> 120s -> 300s`） |
| **FPGA 下位机** | PC | `'U'` | **Unlocked (开锁成功)** | 密码密文核验通过或挑战-应答认证合法；PC 上位机记录日志并抓拍开门者留存 |
| **FPGA 下位机** | PC | `'K'` | **Relocked (重新闭锁)** | 3 秒开锁倒计时结束或按 `C` 键手动提前闭锁；PC 数字孪生仪表盘同步恢复闭锁状态 |
| **FPGA 下位机** | PC | `'E'` | **Password Error (单次输错)** | 单次密码校验或远程挑战应答不通过；PC 上位机记录错误告警日志 |
| **FPGA 下位机** | PC | `'L'` | **Locked (阶梯破解锁定)** | 连续输错 3 次触发硬件阶梯死锁（60s / 120s / 300s）；PC 触发声光报警并启动连拍取证 |
| **FPGA 下位机** | PC | `'T'` | **Lock Timeout End (锁定结束)** | 硬件锁定倒计时归零自动解封；PC 同步解除锁定告警状态 |
| **FPGA 下位机** | PC | `'D'` | **Duress (反挟持静默报警)** | 用户输入胁迫密码 `654321`，表面正常开锁麻痹歹徒，底层静默发 `'D'` 通知上位机后台连拍取证（硬件互斥吞并同拍 `'U'`） |
| **FPGA 下位机** | PC | `'A'` | **Door Alert (门未关好警报)** | 开锁后门磁处于打开状态超过 15 秒未关门；上位机记录超时告警并抓拍 |
| **FPGA 下位机** | PC | `'X'` | **Tamper Alarm (非法撬门警报)** | 未授权闭锁态下门磁被强行撬开；FPGA 锁定报警并周期性上报 `'X'`，上位机紧急录像取证 |

## ⌨️ 4×4 矩阵键盘按键映射与交互定义

开发板板载 4×4 白色微动轻触按键共 16 个物理按键，系统为每个按键赋予了明确的安防与业务功能定义（RTL 内部已适配 180° 旋转补偿，正面视角与丝印完全一致）：

| 键位 | 编码 (Hex) | 键面字符 | 按键类型 | 核心功能与交互行为说明 |
| :---: | :---: | :---: | :---: | :--- |
| **0 ~ 9** | `0x0` ~ `0x9` | `0` ~ `9` | **数字输入** | 密码输入与新密码设置录入。按下一键蜂鸣器发 1kHz 提示音，终端显示动态更新掩码 `*`，数码管显示当前位数。 |
| **\*** | `0xE` | `*` | **退格 / 取消** | **双重容错逻辑**：<br>1. 正在输入字符（`len > 0`）：单步回退删除最后 1 位；<br>2. 缓冲区为空（`len == 0`）：直接**取消当前模式**（取消改密/取消录入/取消应急重置），安全平稳退回待机主界面。 |
| **#** | `0xF` | `#` | **确认 / 提交** | **多模式确认键**：<br>1. **开锁核验**：提交 6~16 位输入进行滑动窗口模式匹配判决（未满 6 位按 `#` 仅发提示音，不扣罚错误次数）；<br>2. **改密/录入/恢复**：提交当前 6 位密码，推进入下一步确认或写入。 |
| **A** | `0xA` | `A` | **新用户设置密码** | **首次录入通道**（仅在默认密码 `123456` 尚未修改时可用；改密后按 `A` 拒绝进入并提示音，防旁人直接篡改）：<br>`按 A` $\to$ 终端显示提示 `输入新密码` $\to$ 输 6 位新密码按 `#` $\to$ 提示 `重复新密码` $\to$ 再次输入按 `#` $\to$ 写入密码寄存器生效。 |
| **B** | `0xB` | `B` | **修改密码 (改密)** | **老用户改密通道**（强权限闭环，验旧改新）：<br>`按 B` $\to$ 终端显示提示 `输入旧密码` $\to$ 按 `#` 校验（输错扣罚并报警退回）$\to$ 验密通过后 `输入新密码` $\to$ 按 `#` $\to$ `重复新密码` $\to$ 按 `#` $\to$ 写入生效。 |
| **C** | `0xC` | `C` | **手动提前闭锁** | 开锁成功后若无需等待 3 秒自动闭锁，按 `C` 可立即提前闭锁（熄灭 LED2 开锁指示灯）并向 PC 上报 `'K'`。 |
| **D** | `0xD` | `D` | **硬件应急恢复** | **忘记密码硬件重置通道**（需先将开发板拨码开关 `SW7 (A14)` 拨上开启硬授权）：<br>待机态 `按 D` $\to$ 终端显示 `应急重置 / 请输入密码` $\to$ 输入 6 位硬件恢复码 `937158` 按 `#` $\to$ 硬件单拍现算 PRESENT 哈希并与片上密文 `0xC905ED` 核验（网表无明文残留），通过后密码重置为初始值 `123456`（连续输错 3 次同样触发 60 秒独立锁定）。 |

> **防呆保护机制**：处于 `A`（录入）或 `B`（改密）模式时超过 **15 秒**无操作，或处于 `D`（应急重置）模式超过 **30 秒**无操作，硬件看门狗定时器自动超时放弃，安全退回待机，防止状态机被占死。

## 💻 PC 上位机安防控制中枢与三层自适应防窥模型

PC 端基于 Python (Tkinter + YOLOv8 + PySerial + OpenCV) 构建，定位为**“环境防窥天眼、设备状态监控与取证黑匣子”**：

### 1. 监控面板大屏功能区布局
* **左半区：实时视觉画面与 AI 目标标注**
  * 直接调用本地/USB 摄像头（`cv2.VideoCapture(0)`），以低延迟帧率呈现。
  * **目标标注框**：
    * **绿色框**：标注正前方的操作者本人（标记 `User: Active`）。
    * **红色告警框**：标注侧身探头、背后聚集逼近的偷窥者（标记 `Peeping Alert!`）。
  * **人脸识别状态指示**：白名单核验状态、单人稳定 2 秒核验开锁按钮引导。
* **右半区：终端显示与锁体环境控制**
  * **终端显示组件**：1:1 动态仿真呈现四行交互菜单、密码掩码与防窥横杠（`----------------`）。
  * **锁体与环境状态**：实时映射底层开锁、闭锁、60s 试错锁定倒计时与门未关严状态。
  * **交互与测试控制按钮**：`[测试 P · 防窥]`、`[测试 S · 解挂]`、`[测试 R · 开锁]`，支持无需摄像头一键模拟联调。
  * **取证存储状态**：一键打开本地数据存储目录。
* **底部区：多标签页管理中枢**
  * **运行日志**：带毫秒级时间戳的事件滚动审计列表，支持一键导出 CSV 报告。
  * **密码管理**：支持在线校验旧常规密码并提交修改新常规密码/胁迫密码。
  * **模拟验收**（`--demo` 模式）：内置全真软件模拟器，支持免硬件全流程演练。

### 2. 自适应防窥与取证判决模型
为了避免背景走动路人频繁误触，PC 端采用空间与时间融合判决模型：
1. **第一层：空间几何 ROI 与身高比例过滤**：设置 `min_person_height_ratio=0.25`，自动剔除背景远处走过的路人。
2. **第二层：双向时间滞后防抖滤波（Temporal Hysteresis）**：多人目标必须持续停留达到 `peep_enter_seconds`（默认 0.8 秒）才触发防窥熄屏 `'P'`；恢复单人/无人且持续达到 `peep_exit_seconds`（默认 1.2 秒）才下发 `'S'` 恢复，彻底杜绝状态频繁抖动。
3. **第三层：人脸核验与事件级自动取证**：单人白名单稳定识别 2.0 秒方可获得核验开锁资格；收到 `'U'`/`'D'`/`'L'`/`'A'`/`'P'` 等事件自动触发快照抓拍（归档至 `data/live/evidence/`）与 15 秒滚动录像（归档至 `data/live/recordings/`）。

## 🔐 密码认证规范与虚位密码机制

1. **日常开锁免录人脸**：
   * 人来到保险箱前，直接敲键盘输入密码即可开锁，无需预先录入人脸库。
   * PC 摄像头仅负责环境防窥与开门自动抓拍留底，不卡控开门权限，保障断网脱机时 100% 独立可用。
2. **6 ~ 16 位自适应虚位密码**：
   * 敲击长度在 **6 至 16 位** 任意浮动（例：`乱码 + 6位真密码 + 乱码 + #`），绝不强制凑满 16 位。
   * FPGA 内部移位 FIFO 永远保存最近 16 位输入，在按 `#` 的瞬间，通过内部 **11 组硬件并行比对器在 20 纳秒（单时钟周期）内全并行完成模式匹配**，纳秒级提取真密码，兼具防旁路推演与超高硬件实时性。

## 🔬 物理级硬件安全攻防与纯板载执行深度剖析 (Physical Security & On-Board Actuator)

为了应对国家级竞赛与工业安防等级的严苛审查，系统在底层硬件（RTL）实施了三项重磅物理级加固：

### 1. 片上 RO-TRNG 环形振荡器物理真随机数发生器 (`rtl/uart_mailman.v`)
- **抗预测与抗重放根基**：远程挑战-应答开锁必须依赖绝对唯一的随机数（Nonce）。传统伪随机数（PRNG）易被监听建模预测。
- **素数自激振荡拓扑**：利用安路 EG4S20 内部反相器微观传输延迟对半导体微热噪声和晶格抖动的敏感性，在硅片上构建 **3-stage、5-stage、7-stage 三组互质素数级自由环形振荡器 (Ring Oscillators)**，加注 `(* syn_keep = "true", keep = "true" *)` 属性防止综合器误优化。
- **Von Neumann 差分去偏**：三环高频相位异或混叠后，在 50MHz 系统时钟域进行双级触发器（2FF）亚稳态采样，并通过相邻采样差分（`ro_sync_d2 ^ ro_sample`）彻底滤除直流偏置，将源源不断的微观物理熵注入 LFSR，使每一次开锁挑战的 Nonce 具备真正的不可预测性。

### 2. 全芯片无明文凭据驻留机制 (`rtl/safe_fsm.v` + `rtl/recovery_mgr.v`)
- **消除比特流与网表明文**：传统电子锁将默认口令或恢复码以明文写在代码中，攻击者通过逆向网表或 JTAG 探针即可轻易提取。
- **PRESENT S-Box 统一混淆**：
  - 主密码：出厂默认值 `123456` 经 PRESENT 4-bit S-Box + 2 轮加盐混淆后，以密文摘要 **`24'hE038C9`** 驻留寄存器；
  - 胁迫密码：`654321` 对应密文摘要 **`24'h1F5F05`**；
  - 应急恢复码：`937158` 对应密文摘要 **`24'hC905ED`**；
- **单向不可逆单拍比对**：无论是键盘输入的虚位滑窗、还是恢复码通道，均在提交瞬间由硬件现算 24 位哈希值与片上密文比对，且在比对完成或按 `*` 撤销时立即执行 `buf <= 0` 内存冲刷，全芯片杜绝明文驻留。

### 3. 纯板载高可靠执行架构 (Native On-Board Actuator Architecture)
- **原生高可靠拓扑**：
  - **开锁电信号与立体反馈**：开锁时板载 `LED2 (B16)` 高电平持续点亮 3 秒，数码管显示 `OPEn`，蜂鸣器奏响和弦，底层串口向 PC 同步上报 `'U'`。
  - **模块化控制核心定位**：系统设计聚焦于工业级高可靠性与标准化复用，将作品提炼为一颗标准化**可嵌入式安全控制核心**，完全基于原生板载资源形成完整的硬件安全闭环，提供标准化的控制信号与通信总线，可零改动无缝适配任意工业锁体与下游执行机构。

## 🚀 快速上手指南 (Quick Start)

### 1. 硬件端：安路 TD 工程构建与烧录

1. 启动 **Anlogic Tang Dynasty (TD)** 软件（推荐版本 TD 5.6+）。
2. 在主菜单点击 `Project` $\to$ `Open Project...`，选择本项目根目录下的 [`lock.al`](./lock.al)。
3. 在左侧 Project View 确认工程文件关联无误：
   - Design Files: `rtl/clk_tick.v`, `rtl/top.v`
   - Constraints: `lock.adc`
4. 双击运行 **Generate Bitstream** 生成比特流固件。
5. 使用 USB 下载线连接开发板 JTAG 接口，通过 **Download** 工具烧录至 FPGA。
6. **验证现象**：板载 `LED0` 以精确的 **1Hz**（0.5s 亮、0.5s 灭）平稳闪烁，说明硬件底座、基准时钟与引脚约束完全正常。

---

### 2. 软件端：上位机启动与联调

上位机支持物理串口连接与脱机模拟运行两种模式：

#### 安装运行环境依赖
```bash
# 建议在 Python 3.9+ 虚拟环境中执行
pip install -r requirements.txt
```

#### 启动 PC 上位机监控主控台
```bash
# 启动可视化安防主控台 (支持自动扫描物理 COM 口与一键联调)
python pc/main.py

# 或双击运行一键演示脚本
pc/run_demo.bat
```
